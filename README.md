# 配电网可靠性评估台

面向配电网规划与教学场景的**交互式可靠性评估工具**：在 10 kV 辐射状馈线上直接编辑元件可靠性参数，实时得到 SAIFI / SAIDI / CAIDI / ASAI / ENS 五项系统指标，并给出薄弱环节排序与方案对比。

纯前端实现，零依赖、零后端、全离线运行，双击 `index.html` 即可使用。

## 解决什么问题

配电网可靠性评估的常规做法是在 Excel 里逐条线路做故障模式后果分析（FMEA），一个 4 段 4 负荷点的算例就要维护几十行公式，改一个参数需要重算全表，且无法直观看出"哪一段最拖后腿"。

本工具把 FMEA 计算过程变成可视化的拓扑交互：

- 点击任一线路段 / 配变 / 负荷点，直接改故障率与修复时间，五项指标与逐点明细同步刷新；
- 分段开关、联络转供两个开关量可随时投退，立刻看到自动化改造带来的指标变化；
- 自动给出各元件对 SAIDI 的贡献排序，定位薄弱环节；
- 一键导出 CSV，便于写入报告。

## 核心功能

| 功能 | 说明 |
|------|------|
| 拓扑可视化 | 单母线 4 段馈线 + 4 台配变 + 4 个负荷点，SVG 绘制，支持点选编辑 |
| 参数编辑 | 线路长度、单位故障率、修复时间；配变容量、故障率、修复时间；负荷点用户数与平均负荷 |
| 指标计算 | SAIFI、SAIDI、CAIDI、ASAI、ENS，含逐负荷点 λ / U / ENS 明细 |
| 运行方式 | 分段开关投退、联络转供投退、故障隔离时间、转供操作时间 |
| 薄弱环节排序 | 按各元件对 SAIDI 的贡献降序排列，取前 5 项 |
| 方案对比 | 无开关 / 仅分段 / 分段+联络 三种方案 SAIDI 横向对比 |
| 结果导出 | 生成带 BOM 的 UTF-8 CSV，Excel 直接打开不乱码 |

## 评估方法与公式

采用**故障模式后果分析法（FMEA）**，对每个负荷点建立串联模型。设元件 $i$ 的故障率为 $\lambda_i$（次/年），故障后该负荷点的停电时长为 $d_{i,k}$（h），则负荷点 $k$ 的指标为：

$$\lambda_k=\sum_i \lambda_i,\qquad U_k=\sum_i \lambda_i\, d_{i,k}$$

系统指标按用户数加权：

$$SAIFI=\frac{\sum_k \lambda_k N_k}{\sum_k N_k},\qquad SAIDI=\frac{\sum_k U_k N_k}{\sum_k N_k},\qquad CAIDI=\frac{SAIDI}{SAIFI}$$

$$ASAI=1-\frac{SAIDI}{8760},\qquad ENS=\sum_k P_k U_k$$

停电时长 $d_{i,k}$ 按故障位置与开关配置确定，这是本工具与"纯串联"简化模型的关键差异：

| 故障元件 | 负荷点相对位置 | 停电时长 |
|----------|----------------|----------|
| 线路段 | 位于故障段上游 | 有分段开关取隔离时间 $t_{iso}$，否则取修复时间 $r_i$ |
| 线路段 | 所在节点处于故障段下游端 | 取修复时间 $r_i$（故障段必须修复） |
| 线路段 | 位于故障段下游 | 有联络取转供时间 $t_{trans}$，否则取修复时间 $r_i$ |
| 配变 | 仅本负荷点 | 取配变修复时间 $r_T$（高压熔断器就地隔离，不波及上游） |

默认参数取城网架空线路典型值：线路 $0.08$ 次/(年·km)、$r=3.5$ h；配变 $0.015$ 次/年、$r=6$ h；$t_{iso}=0.5$ h、$t_{trans}=1.0$ h。

## 适用与局限

- 适用于**辐射状中压配电网**的规划初筛、教学演示与方案比选；
- 模型为解析法 FMEA，不含光伏/储能等分布式电源的孤岛效应，也未计及计划检修与预安排停电；
- 联络转供按"容量充足即可转供"处理，未做转供容量越限校验；
- 若要评估含分布式电源、含环网的场景，需要在模型层扩展最小割集或序贯蒙特卡洛仿真。

## 技术说明

- 原生 HTML + CSS + JavaScript，无框架、无构建步骤、无外部 CDN，断网可用；
- 计算引擎为纯函数 `compute(state)`，输入状态即输出全部指标，便于单元测试与二次开发；
- 拓扑使用 SVG 动态生成，坐标按馈线节点线性映射，可扩展为任意段数。
